# Security DNS

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Platforms](https://img.shields.io/badge/platform-Linux%20%7C%20Windows-blue.svg)](#requirements)

**Security DNS** hides your DNS lookups from your Internet Service Provider (ISP), makes it harder for Deep Packet Inspection (DPI) equipment to read website names, and gives you a numbered menu to switch between protection modes. It runs in English or Arabic.

It installs as a local application: a command on Linux with a `.desktop` entry, and Start Menu and Desktop shortcuts on Windows. Every change is backed up before it is made, and the uninstaller restores those exact backups.

> **Important:** No local tool can completely hide your traffic from your ISP while keeping your apparent location. Read [Location and IP Address Trade-off](#location-and-ip-address-trade-off) before you use modes 2 and 3.

## Modes

The first installation enables encrypted DNS and starts **mode 1**. Choose a mode from the menu at any time. Only one routing mode runs at once. Every switch stops the current mode before starting the new one.

| Option | Mode | What it does | Keeps your public IP? | Hides destination IPs from ISP? |
|---|---|---|---|---|
| **1** | SpoofDPI bypass | Local DPI-bypass proxy that splits the TLS handshake. Startup arguments are chosen to match the installed SpoofDPI build | Yes | No |
| **2** | Cloudflare WARP | Official Cloudflare client; all traffic goes through an encrypted tunnel to Cloudflare | No | Yes |
| **3** | WireGuard (wgcf) | WireGuard tunnel using a WARP profile generated by `wgcf` | No | Yes |
| **0** | Off | Stops the proxy and tunnels; keeps encrypted DNS | Yes | No |

Modes 2 and 3 trade location for destination privacy. Read the next section before enabling them.

Encrypted DNS is always on:

- **Linux:** DNS-over-TLS through `systemd-resolved` with `1.1.1.1` and `1.0.0.1`. `DNSOverTLS=yes`, `DNSSEC=allow-downgrade`, and `Domains=~.` send every lookup through these resolvers. `FallbackDNS=` is empty, so queries do not leak to DHCP or hardcoded fallback servers.
- **Windows:** DNS-over-HTTPS with Cloudflare templates on active physical adapters, with UDP fallback disabled. This requires Windows 10 version 2004 (build 19041) or newer, including Windows 11. Older builds keep their existing DNS and show a warning, so queries are never sent in plaintext.

## What Is and Is Not Hidden

| Information | Mode 1 | Modes 2 and 3 | Mode 0 |
|---|---|---|---|
| DNS lookups (which domains you resolve) | Hidden | Hidden | Hidden |
| Website name in the TLS handshake (SNI) | Mostly hidden (fragmentation; full on ECH sites when ECH is enabled) | Hidden inside the tunnel | Mostly hidden |
| Destination IP addresses | **Visible** | **Hidden** (ISP sees only a connection to Cloudflare) | **Visible** |
| Traffic volume and timing | Visible | Visible, as traffic to Cloudflare | Visible |
| Public IP address | Unchanged | Changes to a Cloudflare address | Unchanged |
| Apparent country | Unchanged | **May change** | Unchanged |
| QUIC / HTTP/3 traffic | Visible unless disabled in the browser | Tunneled | Visible unless disabled |
| Apps that ignore system proxy settings | Not protected | Protected while the tunnel is up | Not protected |

With modes 2 and 3, your ISP still sees a connection to Cloudflare, and Cloudflare can see your traffic. The protection comes from trusting Cloudflare instead of your ISP. Check the laws in your country regarding circumvention and privacy tools before you use them. WARP may be restricted or blocked in some places.

## Location and IP Address Trade-off

The goal of hiding destination IPs from your ISP while keeping your apparent location cannot be fully met by this tool. The reasons are structural:

- A tunnel that hides destinations from your ISP must send your traffic out from somewhere else.
- WARP exits from the Cloudflare data center closest to you, which may be in another country. Websites that geolocate by IP may show that country.
- A VPN with an exit in your own country keeps your apparent location, but then the VPN provider sees your destinations instead of your ISP.

The menu warns you and asks for confirmation before it switches to mode 2 or 3. After switching, compare your apparent country on an IP geolocation site in mode 1 or 0 and in mode 2 or 3. If it changes and that matters, switch back.

## Requirements

**Linux**

- x86_64 (amd64) and systemd with `systemd-resolved`
- Root access through `sudo`
- apt-based (Debian, Ubuntu) or dnf-based (Fedora, RHEL family) systems for mode 2
- Network access to `api.github.com`, `github.com`, `1.1.1.1`, `pkg.cloudflareclient.com`, and `raw.githubusercontent.com`
- A desktop environment with `x-terminal-emulator` for the application menu entry (the command-line menu works everywhere)

**Windows**

- Windows 10 version 2004 (build 19041) or newer, including Windows 11, for system-wide DNS-over-HTTPS
- Windows PowerShell 5.1 or PowerShell 7, in an elevated (Administrator) session
- Network access to `api.github.com`, `raw.githubusercontent.com`, `downloads.cloudflareclient.com`, and WireGuard's release downloads

## Installation

### Linux

```bash
curl -fsSL https://raw.githubusercontent.com/arcalc/setup_privacy/main/install.sh | sudo bash
```

The first run:

1. Asks you to choose a language: `1) English` or `2) العربية`.
2. Installs missing base tools (`curl`, `wget`, `tar`, `iproute2`, `ca-certificates`).
3. Backs up `resolved.conf`, `/etc/resolv.conf`, `/etc/environment`, and each desktop user's GNOME and KDE proxy settings.
4. Installs the application to `/usr/local/bin/security-dns`, the uninstaller to `/usr/local/lib/security-dns/uninstall.sh`, and a desktop entry.
5. Downloads the latest SpoofDPI release. The checksum is verified when one is published.
6. Configures DNS-over-TLS, starts mode 1, and sets the system and desktop proxy automatically.
7. Opens the menu.

Open the menu later with:

```bash
sudo security-dns
```

You can also launch **Security DNS** from your applications menu. It opens a terminal and asks for your password.

### Windows

Open **PowerShell as Administrator** and run:

```powershell
irm https://raw.githubusercontent.com/arcalc/setup_privacy/main/install.ps1 | iex
```

The first run:

1. Asks you to choose a language: `1) English` or `2) العربية`.
2. Backs up the proxy registry values, per-adapter DNS settings, DoH entries, and any existing startup launcher.
3. Installs the application to `C:\ProgramData\SecurityDNS`, with the menu script and uninstaller.
4. Enables DNS-over-HTTPS on active physical adapters, or shows a warning on older builds.
5. Downloads the latest SpoofDPI release, starts mode 1, and sets the system proxy automatically.
6. Creates **Security DNS** shortcuts in the Start Menu and on the Desktop. Both open the menu as administrator.

> **Security note:** Piping a remote script into PowerShell or a shell runs code you have not read. Download the file first with `irm ... -OutFile`, review it, and then run it, especially on machines you care about.

## Using the Menu

```text
  Security DNS v2.2.0  |  current mode: 1

  1) SpoofDPI bypass        keeps your public IP
  2) Cloudflare WARP        hides destination IPs; changes public IP
  3) WireGuard (wgcf)       hides destination IPs; changes public IP
  0) Off                    stops proxy and tunnels; keeps encrypted DNS
  4) Status
  5) Install missing dependencies
  6) Check for updates
  7) Restore original settings (keep app and dependencies)
  8) Uninstall completely
  q) Quit
```

The menu appears in the language you chose at startup. Pick a number and press Enter.

- **1** and **0** apply immediately.
- **2** and **3** show a warning and ask you to confirm before anything changes.
- **4** prints the current mode, the state of the proxy, WireGuard, and WARP, and the DNS status.
- **5** installs any missing dependencies: base tools, `wireguard-tools`, `wgcf`, and the Cloudflare WARP client. It does not register WARP or connect it. That happens only when you choose mode 2.
- **6** checks for updates (see [Updates](#updates)).
- **7** restores your original network, DNS, and proxy settings from the backups and stops all tunnels. The application, dependencies, shortcuts, and backups stay installed. Use it when you want the system back to its original state without losing the tools. Modes 0 to 3 turn encrypted DNS back on when you select them.
- **8** uninstalls everything after you confirm.

Every mode switch stops all routing first, then starts only the chosen mode. Packages and tools that were already on the system are left in place when you uninstall.

## Updates

Choose **6** in the menu. The check covers:

- **The script:** compares the version with the one in the repository. After your confirmation, it replaces the menu and uninstaller. A downloaded script is syntax-checked before it replaces the installed one.
- **SpoofDPI:** resolves the latest release from the GitHub API and installs it only if it differs from the installed version.
- **wgcf:** resolves the latest release and installs it if it differs.
- **Cloudflare WARP:** upgraded through your package manager on Linux. The Windows client updates itself.

After a script update, reopen the menu to use the new version.

## Browser Settings

Two browser settings complement the tool. Neither replaces the other.

### Enable ECH

**Encrypted Client Hello (ECH)** encrypts the Server Name Indication (SNI) field, which otherwise reveals the website name. It protects only connections to sites that publish ECH keys, and the browser fetches those keys through DNS, so ECH works best with the encrypted DNS configured here.

- **Firefox:** open `about:config`, then set `network.dns.echconfig.enabled` and `network.dns.http3_echconfig.enabled` to `true`.
- **Chrome, Edge, and other Chromium browsers:** open `chrome://flags/#encrypted-client-hello`, set it to **Enabled**, and restart. Option names change between versions, so search the flags page for "ECH" if you cannot find it.

### Disable QUIC / HTTP/3

QUIC runs over UDP and does not pass through an HTTP proxy. Left enabled, it can bypass SpoofDPI in mode 1 and expose the hostname.

- **Firefox:** in `about:config`, set `network.http.http3.enable` to `false`.
- **Chromium:** open `chrome://flags/#enable-quic` and set it to **Disabled**.

### Manual proxy (desktops the script does not detect)

- **Address:** `127.0.0.1`
- **Port:** `8080`, or `8081` if 8080 was busy at install time
- **Protocols:** HTTP and HTTPS
- **Exceptions:** `localhost, 127.0.0.0/8, ::1`

## Verifying the Setup

**Linux**

```bash
sudo security-dns          # then choose 4 for status
resolvectl status          # the global section should show DNSOverTLS and 1.1.1.1 / 1.0.0.1
ss -ltn | grep -E ':(8080|8081)\s'
curl -I -x http://127.0.0.1:8080 https://example.com   # mode 1 only
```

**Windows**

```powershell
Get-DnsClientDohServerAddress      # should list 1.1.1.1 and 1.0.0.1
Get-NetTCPConnection -State Listen -LocalPort 8080,8081 -ErrorAction SilentlyContinue
```

To check your apparent location and IP address, open an IP geolocation site in a browser in each mode and compare the results.

## Uninstalling

Choose **8** in the menu for a full uninstall. To restore the original settings only, choose **7** in the menu, or run `sudo bash /usr/local/lib/security-dns/uninstall.sh --restore-only` (Windows: `.\uninstall.ps1 -RestoreOnly`). For a full uninstall, run:

```bash
sudo bash /usr/local/lib/security-dns/uninstall.sh          # Linux
```

```powershell
& "C:\ProgramData\SecurityDNS\uninstall.ps1"                 # Windows, elevated
```

The uninstaller:

- Stops SpoofDPI, WireGuard, and WARP.
- Disconnects and removes WARP only if Security DNS installed it. A WARP client that was already present is left alone.
- Removes the WireGuard profile, `wgcf`, and the WireGuard tools only if Security DNS added them.
- Restores `resolved.conf`, `/etc/resolv.conf`, `/etc/environment`, and each user's GNOME and KDE proxy settings. On Windows it restores DNS, DoH entries, proxy registry values, and the startup launcher.
- Removes the service, the SpoofDPI binary, the menu, the desktop entry, and the shortcuts.
- Deletes the backups only after everything is restored.

If a desktop user's GNOME settings cannot be restored because that user is not logged in, the uninstaller keeps its backups and reports the pending step. Log in as that user and run the uninstaller again.

## Troubleshooting

**Ports 8080 and 8081 are both busy.** Stop the application using them, then run the installer again.

**Mode 2 or 3 is not connected.** Run `warp-cli status` on Linux (Windows: `warp-cli.exe status` in `C:\Program Files\Cloudflare\Cloudflare WARP`), or `systemctl status wg-quick@security-dns` on Linux. DNS encryption keeps working when a tunnel fails, so you can switch back to mode 1 or 0 from the menu.

**My apparent country changed in mode 2 or 3.** This is the exit-location trade-off described above. Switch back to mode 1 or 0 if it matters for the sites you use.

**Websites fail in mode 1.** Check the service with `systemctl status security-dns` (Linux) or `Get-Process spoofdpi` (Windows). If the proxy is down, switch to mode 0 from the menu.

**Windows reports that DoH is not supported.** Your build is older than 19041 (Windows 10 version 2004). Enable Secure DNS in your browser instead. In Chrome or Edge, go to Settings, Privacy and security, Security, Use secure DNS, and choose Cloudflare. In Firefox, go to Settings, Privacy & Security, DNS over HTTPS.

**The Arabic text looks garbled in Windows PowerShell.** Make sure you downloaded `install.ps1` with its UTF-8 byte-order mark intact. Running it from a shell that uses a different encoding can break the display.

**NetworkManager overrides DNS on Linux.** Make sure NetworkManager uses `systemd-resolved` (`dns=systemd-resolved`).

**The Windows shortcut does not open the menu.** Approve the administrator prompt. Shortcuts point to `C:\ProgramData\SecurityDNS\security-dns.ps1`. If that file is missing, reinstall.

## Security Notes

- The scripts store no credentials and send no personal data. Network requests go only to the GitHub API and release downloads, Cloudflare's WARP package and download servers, and the DNS resolvers you configured.
- SpoofDPI listens only on `127.0.0.1`.
- Downloads are verified with SHA-256 when the release publishes checksums. Otherwise the installer prints a warning.
- The Linux WARP repository is signed with Cloudflare's key, stored as a keyring file that the uninstaller removes.
- Updates are syntax-checked before they replace the installed script.
- To avoid GitHub API rate limits, set `GITHUB_TOKEN` to a read-only personal access token before running the installer.
- Report security issues through GitHub's private vulnerability reporting, not as public issues.
