How it protects you

Two independent layers work together: encrypted DNS and a local proxy that defeats common DPI techniques.

🔒

Encrypted DNS

DNS-over-TLS on Linux and DNS-over-HTTPS on Windows, both through Cloudflare 1.1.1.1. Queries are never sent in plaintext.

🛡

DPI bypass proxy

SpoofDPI runs locally and splits TLS handshakes so inspection equipment cannot read the website name in a single packet.

⚡

Zero configuration

One command sets up the proxy, DNS, and system proxy settings. The latest SpoofDPI release is fetched automatically.

↺

Perfect undo

Every changed setting is backed up first. The uninstaller restores the exact previous state, file by file.

🔐

Leak protection

Plaintext fallbacks are disabled. Linux routes all lookups through the encrypted resolver, and Windows disables UDP fallback.

👁

Open and auditable

Plain shell and PowerShell scripts with no binary blobs from us. Downloads are checksum-verified when the release publishes checksums.

Install in one command

Run the command for your system. Windows needs an elevated (Administrator) PowerShell window.

Linux

curl -fsSL https://raw.githubusercontent.com/arcalc/setup_privacy/main/install.sh | sudo bash

Uninstall:

curl -fsSL https://raw.githubusercontent.com/arcalc/setup_privacy/main/install.sh | sudo bash -s -- --uninstall

Windows (Administrator PowerShell)

irm https://raw.githubusercontent.com/arcalc/setup_privacy/main/install.ps1 | iex

Uninstall (downloads the script first):

$s = "$env:TEMP\security-dns-install.ps1"; irm https://raw.githubusercontent.com/arcalc/setup_privacy/main/install.ps1 -OutFile $s; & $s -Uninstall
Review before you run. Piped scripts run immediately. The source is public, so you can read install.sh and install.ps1 first.

After installing

  1. Restart your browser completely.
  2. Enable ECH (Encrypted Client Hello) in your browser to hide the website name from the network.
  3. Disable QUIC / HTTP/3 in your browser so traffic cannot bypass the proxy.
  4. Read the README for manual steps on uncommon desktops.

What is hidden, and what is not

No local tool can make your ISP completely blind. Here is an honest summary.

Hidden

  • Your DNS lookups, encrypted with DoT or DoH
  • The website name in most HTTPS connections, through handshake fragmentation
  • Website names on sites that support ECH, when ECH is enabled in your browser

Still visible

  • Destination IP addresses of the servers you connect to
  • Traffic volume and timing
  • QUIC / HTTP/3 traffic, unless you disable it in your browser
  • Applications that ignore the system proxy settings
